# An autonomous loop

I've been doing some experimentation with agentic development in autonomous loops,
for quite some time in `~/source/personal/exploring-claude` and recently
I wanted to write a blog post about the process and expected that starting with the same 
basic prompt would somehow (magically) produce a similar result that could be the subject
for the blog post.

So I started the project at `~/source/personal/blog-posts/a-basic-autonomous-loop`, 
and then started a couple more:

-  `~/source/personal/blog-posts/an-autonomous-loop`
-  `~/source/personal/blog-posts/an-autonomous-loop-2`

All with totally different results.

Seeing that, I suddenly realized that I was following the vibe coding "process", and expecting 
consistent results, which is completely non-sense.

So, for this iteration, I want to create a detailed-enough brief that can be used to start the next
experiment, taking the learnings from the previous experimentation, specially in the `exploring-claude`
project. 

specially important is the `~/source/personal/exploring-claude/docs/design-notes/executable-loop-harness.md`

So, please, let's start a discussion on this topic to arrive at a new brief document, that will start 
the next-generation agentic loop experiment, that incorporates the learnings and most interesting parts 
from the above experiments.
